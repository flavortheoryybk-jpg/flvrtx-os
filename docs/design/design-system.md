# FLVRTX Design System

The FLVRTX Design System defines the visual language and reusable UI patterns used across the platform.

---

# Design Principles

FLVRTX is built around five principles:

- Premium
- Clean
- Minimal
- Educational
- Food First

Every UI element should support these principles.

---

# Shadows

Use soft shadows.

Avoid heavy elevation.

Cards should feel light and premium.

---

# Buttons

Primary

- Filled
- Green
- White text

Secondary

- White background
- Border
- Dark text

Text Button

- No background
- Primary color

---

# Cards

Cards should include:

- Rounded corners
- Soft shadow
- Comfortable spacing
- Hover animation

---

# Icons

Library

Lucide Icons

Guidelines

- Keep consistent sizing
- Use outline icons
- Avoid mixing icon sets

---

# Layout

Use:

<x-ui.section>

for page sections.

Use:

<x-ui.container>

for width constraints.

---

# Responsive Design

Target devices:

- Mobile
- Tablet
- Laptop
- Desktop

Always design mobile first.

---

# Animations

Animations should be subtle.

Examples:

- Fade
- Scale
- Hover
- Smooth transitions

Avoid distracting motion.

---

# Accessibility

Ensure:

- Proper color contrast
- Visible focus states
- Keyboard navigation
- Alt text
- Semantic HTML

---

# Philosophy

The interface should never compete with the food.

Photography and content are always the primary focus.
