# Rank Math SEO Configuration

This document defines the SEO configuration used by FLVRTX.

---

# SEO Philosophy

FLVRTX is built with an SEO-first approach.

Goals:

- High search visibility
- Rich snippets
- Fast loading pages
- Strong internal linking
- High-quality content

---

# Plugin

Rank Math SEO

---

# Global Settings

## Titles

Use descriptive page titles.

Examples:

Recipe Name | FLVRTX

Article Title | Learn | FLVRTX

Product Name | Recommendation | FLVRTX

---

## Meta Descriptions

Every page must include a unique meta description.

Recommended length:

140–160 characters.

---

## Focus Keywords

Each page should target one primary keyword.

Examples:

gongura boti

how to season cast iron

tomato chutney recipe

---

# Social Metadata

Enable:

- Open Graph
- Twitter Cards

Include:

- Featured Image
- Title
- Description

---

# Indexing

Index:

- Recipes
- Learn
- Watch
- Recommendations
- Categories

No Index:

- Search Results
- Author Archives (if unused)
- Attachment Pages

---

# Breadcrumbs

Enable breadcrumbs.

Use consistent hierarchy.

Example:

Home

↓

Recipes

↓

Chicken Curry

---

# Redirections

Create redirects for:

- Deleted pages
- Changed URLs
- Broken links

Avoid redirect chains.

---

# 404 Monitor

Enable the Rank Math 404 Monitor.

Review regularly.

Fix broken links promptly.

---

# Image SEO

Every image should include:

- Meaningful filename
- Alt text
- Optimized file size

---

# Internal Linking

Every page should connect to related content.

Examples:

Recipe

↓

Learn

↓

Watch

↓

Recommendation

---

# SEO Checklist

Before publishing:

- SEO Title
- Meta Description
- Focus Keyword
- Featured Image
- Alt Text
- Internal Links
- Schema Validation

---

# Goal

Every page should provide valuable content while following modern SEO best practices.
