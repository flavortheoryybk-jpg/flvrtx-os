# FLVRTX Architecture

## Overview

FLVRTX is a premium food platform built on WordPress using Sage 11.

The architecture follows a modular, component-based approach to ensure scalability, maintainability, and high performance.

---

## Technology Stack

- WordPress
- Sage 11
- Blade Templates
- Tailwind CSS v4
- Alpine.js
- Vite
- ACF Pro
- CPT UI
- Rank Math SEO
- LiteSpeed Cache
- ShortPixel

---

## Core Principles

- Component-first architecture
- Reusable Blade components
- Content managed with ACF
- Performance-first design
- Mobile-first responsive layout
- SEO-first development
- Modular JavaScript
- Minimal plugin dependency

---

## Content Types

- Recipes
- Learn
- Watch
- Recommendations

Each content type has its own templates, archive pages, cards, and reusable components.

---

## Design Philosophy

Understand Food. Cook With Confidence.

Every page should educate, inspire, and simplify cooking while maintaining a premium visual experience.
